# Program Chair Content Validation

Every record, paper, and report goes through the Program Chair before it is published.

## Flow

1. **Draft.** The submitter creates the record or uploads the file.
2. **Submitted.** The submitter sends it for review.
3. **Under review.** The Program Chair checks the content.
4. **Approved or Returned.** Approved goes forward. Returned goes back with comments.
5. **Published.** An admin publishes approved content.

## Rules

- Only Program Chairs can approve content for their program.
- A returned item keeps its comments and history.
- Published content can only be changed by a new submission.
- Every step is logged: who, what, when.
- Full papers follow the same flow as any other record.
