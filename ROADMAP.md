# Roadmap

Target dates are rough and will move. Status: ✅ done · 🔨 in progress · ⬜ planned.

## Phase 0 — Foundation (Nov 2026)

- ⬜ Create the private GitHub repository and set up this structure
- ⬜ Move the existing research platform into `committees/01-research`
- ⬜ Move shared code into `platform/` (login, roles, database, AI, PDF export)
- ⬜ Confirm committees, heads, and who gets access with the Dean

## Phase 1 — Research Committee v1

- ✅ Research dashboard with admin-first registration
- ✅ Filter and export to PDF, file attachments, AI follow-up questions
- ✅ One-file Windows install for the Dean
- 🔨 Full papers stored in the database
- ⬜ Program Chair content validation for research records
- ⬜ Import from the live spreadsheet (needs permission)

## Phase 2 — Core Platform

- ⬜ Roles: Admin, Dean, Program Chair, Committee Head, Faculty, Staff
- ⬜ Validation workflow: Submitted → Program Chair review → Approved or Returned → Published
- ⬜ Change requests for non-admins, with admin approval
- ⬜ Audit log (who changed what, and when)
- ⬜ Shared file storage and search across all committees
- ⬜ Backups

## Phase 3 — Faculty Development and Quality Assurance

Faculty Development
- ⬜ Faculty profiling
- ⬜ Linking of syllabus to faculty and courses
- ⬜ Activity reports
- ⬜ Faculty report submissions with Program Chair validation

Quality Assurance
- ⬜ Accreditation document tracking by area and standard
- ⬜ Center of Excellence requirements and evidence
- ⬜ Evidence linked to records from other committees

## Phase 4 — Community Extension, Alumni, Student Development

- ⬜ Community Extension: projects, partners, beneficiaries, activity reports
- ⬜ Alumni: directory, employment and licensure tracking, tracer data
- ⬜ Student Development: organizations, activities, achievements, records

## Phase 5 — Other Programs and Rollout

- ⬜ Other Programs: flexible module for new college programs
- ⬜ Local AI summaries across all committees
- ⬜ Move to a UC IT spare PC as the server
- ⬜ Online and LAN access
- ⬜ User guide and training for committee heads
